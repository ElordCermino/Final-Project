# Activity 4: Google Slides Interactive Presentation

This activity was a group presentation (BSN 4-F | Group 2) about **Google Slides**—covering its definition, purpose, key features, practical uses (interactive learning modules, digital posters, online quizzes, project planning, and digital portfolios), and an interactive "Pass the Box!" quiz game.

- **Submission File:** [Electives_Group-2-Slides (1).pdf](Electives_Group-2-Slides%20(1).pdf)

## What Have I Learned?

- **Key Concepts & Skills:** I learned how Google Slides supports real-time collaboration, cloud storage, multimedia integration, and hyperlink-based interactive navigation beyond standard slide decks.
- **Challenge & Solution:** Coordinating slide design and quiz flow across a group while keeping the presentation engaging was challenging; we solved this by dividing sections clearly and using a consistent visual theme with an interactive "Pass the Box!" game format.
- **Future Application:** I can apply these interactive presentation techniques when facilitating nursing case studies, group reports, or patient/community health education sessions.
