# Activity 7: Comparative Resume Generation using Multiple LLMs

This activity compared two large language models—**ClaudeAI** and **ChatGPT**—using the same prompt to generate a one-page professional resume, evaluating their outputs across structure, clarity, formatting, and overall quality.

- **Submission File:** [CERMINO_ACTIVITY7.pdf](CERMINO_ACTIVITY7.pdf)

## What Have I Learned?

- **Key Concepts & Skills:** I learned how different LLMs interpret formatting constraints and space management—ChatGPT condensed everything onto a scannable one-page layout, while ClaudeAI produced a more exhaustive two-page version with full reference details.
- **Challenge & Solution:** Neither first draft was completely ready to submit on its own (ClaudeAI split a section across a page break and had minor formatting glitches, while ChatGPT omitted full reference contact details); I solved this by using ChatGPT's compact one-page structure as the base while keeping ClaudeAI's complete reference list on hand for local hospital applications.
- **Future Application:** I can apply this comparative approach whenever using AI for professional writing—critically evaluating and combining the strongest parts of multiple outputs rather than accepting the first draft.
