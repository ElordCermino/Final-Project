# Activity 6: Personal Resume Website

This activity involved building a one-page interactive nursing resume website using AI-assisted web development. The site presents my clinical nursing rotations (Medical-Surgical, Perioperative, Emergency, Maternal and Child, and Psychiatric Nursing), education, Basic Life Support certification, seminars, and character references, complete with specialty filters and a print-to-PDF feature.

- **Submission File:** [CERMINO_ACTIVITY6.pdf](CERMINO_ACTIVITY6.pdf)

## What Have I Learned?

- **Key Concepts & Skills:** I learned how structured prompting and providing clear design references (such as a resume PDF and a navy/gold/neutral color palette) shape the quality of an AI-generated web portfolio, as well as how to manage web assets and deploy static HTML sites.
- **Challenge & Solution:** Troubleshooting missing or broken asset references and ensuring the layout remained clean and print-ready was challenging; I solved this by verifying exact file paths and testing the print-to-PDF and filter features.
- **Future Application:** Having a mobile-friendly, print-ready online resume gives me a modern way to present my clinical credentials to future healthcare employers and nurse managers.
